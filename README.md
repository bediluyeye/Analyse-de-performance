# 📊 Analyse de la Performance des Employés

## 🧾 Contexte

Une entreprise souhaite améliorer la productivité de ses employés et mieux comprendre les facteurs qui influencent leurs performances.

Le service des ressources humaines dispose de plusieurs informations sur les employés :

* heures de travail
* formations suivies
* ancienneté (années d’expérience)
* absences
* satisfaction au travail
* département

L’objectif est d’analyser ces données afin d’identifier les facteurs qui influencent réellement la performance des employés, et de construire un modèle capable de prédire leur score de performance.

---

## 🎯 Objectif principal

Étudier les performances des employés et développer un modèle de machine learning capable de prédire leur **score de performance** à partir des données disponibles.

---

## 🧠 Compétences visées

Ce projet permet de pratiquer :

* Data Cleaning
* Analyse exploratoire des données (EDA)
* Analyse de corrélation
* Régression linéaire
* Visualisation de données
* Interprétation métier

---

# 🧪 TRAVAIL DEMANDÉ

## 🧹 Partie 1 — Nettoyage des données

Le stagiaire devra :

* Charger le fichier CSV
* Vérifier les valeurs manquantes
* Détecter les doublons
* Vérifier les incohérences
* Corriger les erreurs éventuelles
* Préparer les données pour l’analyse

---

## 📊 Partie 2 — Analyse exploratoire (EDA)

Répondre aux questions suivantes :

1. Quel département a les meilleures performances ?
2. Les employés qui travaillent plus performent-ils mieux ?
3. L’expérience influence-t-elle la performance ?
4. Les absences réduisent-elles la performance ?
5. Les formations améliorent-elles réellement les résultats ?
6. La satisfaction des employés a-t-elle un impact ?

### 📈 Résultats attendus :

* Graphiques (bar charts, scatter plots, etc.)
* Tableaux récapitulatifs
* Interprétation métier claire

---

## 🔗 Partie 3 — Analyse de corrélation

Identifier les variables les plus liées à la performance :

Exemples :

* heures de travail
* absences
* expérience
* satisfaction
* formations suivies

### 🎯 Objectif :

Déterminer les facteurs qui influencent le plus la productivité.

---

## 🤖 Partie 4 — Modèle prédictif

Construire un modèle de **régression linéaire** pour prédire :

> `performance_score`

### Étapes :

* Choisir les variables explicatives
* Diviser les données (train/test)
* Entraîner le modèle
* Tester les performances
* Interpréter les résultats (coefficients, R², MSE)

---

## 💡 Partie 5 — Recommandations Business

À partir des résultats, proposer des actions concrètes pour améliorer la performance des employés :

### Recommandations possibles :

* Réduire l’absentéisme
* Augmenter les formations
* Améliorer la satisfaction interne
* Mettre en place un suivi des absences récurrentes
* Introduire des politiques de flexibilité (télétravail, horaires adaptés)


## 📌 Conclusion

Ce projet permet de transformer des données RH en insights exploitables afin d’aider l’entreprise à prendre des décisions basées sur les données (data-driven decisions).
